access · 申请名额

从官网「申请名额」表单进来的人。开名额走的是和上面「给一个人开名额」 一模一样的那条路(没账号会替他建、然后发一封通知信);不开只是把这条标掉, 不通知对方 —— 要不要回他一句,由你决定。两个动作都会留在下面的操作留痕里。

⚠️ 这是代付口径:服务端只看得见经过服务器的动作。没登录的人、 以及整条链路都在本机跑的动作(本机识别 + 不整理),一次都不会出现在这里。

models · 模型与供应商

新供应商、端点的 host 白名单、key 名只能经迁移加 / 改 —— 后台只改已有那一家的显示名 / 端点 / 参数 / 启用。

换模型 / 改供应商:先「试打」(真打一次最小请求),回 OK 才能点「生效」。 生效后客户端下一次请求就走新的,不用发版。

keys · 密钥

这家还没用在任何档,试打要指定一个模型 id。

这里只显示末四位 / 长度 / 指纹前 8 位,库里的值加密存着、回包里永远没有它。
新 key 生效后请在上游吊销旧 key;在途请求可能失败一两次。这里换掉的只是 Murmur 用哪一把,旧的那把在上游仍然活着。
发信(Resend)与 Stripe webhook 两把本期不在这里换:另一个函数只读控制台里的那份,这里换了会把发信弄断。

pricing · 单价

单位是微美元(百万分之一美元)每单位。改了影响下一把 lease 的预扣与之后的结算,已经签出去的不追溯。

remote config · 远程配置

flags & defaults · 开关与默认值

「默认开」只影响从没自己选过的用户,不盖过用户的选择;「紧急关」盖过用户选择,界面显示「暂时关闭」。 「公开」= 匿名的 /config/public 也会下发。数值要在范围内(越界这里直接拦、发布按钮变灰);空着 = 不下发、用内置。

scene styles · 场景风格

每个场景四个旋钮 + 一行补充(extra):≤ 200 字、不许换行 / 花括号 / 反引号。 补充放在整理规则之后,优先级低于规则;含 ignore / forget / system / assistant 这类词只提醒、不拦。

copy · 文案

中英各一,≤ 200 字、不许换行。两格都清空 = 删掉这条 = 恢复内置文案。

config audit · 配置改动

「回退到这一版」= 把这一行改动之前的样子写回去(它自己也会记一行)。密钥不能回退 —— 旧 key 该去上游吊销,不该再用。

seat · 给一个人开名额

填邮箱就行。没有账号会替他建一个,然后发一封「名额开好了」的信。 他之后正常登录即可 —— 已经有名额的人再开一次不会重复,只会把封禁/暂停解回来。

invite · 铸一张邀请码

可以线下发 —— 拿到码的人自己就能开通,不用你在场。 ⚠️ 明文只显示这一次,关掉就再也取不回来(库里只有哈希)。
